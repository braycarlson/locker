# locker

A peripheral locker for Windows and Linux. The tool disables the keyboard, the mouse, or both from a shortcut or the tray menu, so a desk and its devices can be cleaned without unintended input. The default lock is Ctrl+Alt+L, the default unlock is typing `UNLOCK`, and a two-second hold of both Shift keys is a rescue that releases the lock. The `config.toml` file sets these shortcuts and can also disable or remap Super key shortcuts, and it reloads on change.
